For developers

One request, one reply.

NOIR is a static front end. Keep your provider keys on your server, expose a single endpoint, and send back a finished media URL.

  • JSON in, media URL out. No SDK, no build step.
  • Width, height and seed go out with every request.
  • https, data: and same-origin results are accepted.
  • A 120 second timeout, and a cancel button for the user.
POST /api/generate
// request
{
  "type": "image",
  "prompt": "A calm moonlit ocean",
  "negative_prompt": "",
  "style": "cinematic",
  "aspect_ratio": "16:9",
  "quality": "high",
  "width": 960,
  "height": 540,
  "seed": 482913775
}

// reply
{ "image_url": "https://your-server.example/out.png" }

Questions

Straight answers.

Does NOIR include real AI image generation?

Not by itself. The built-in renderer makes deterministic procedural artwork so you can try the whole workflow offline. For a real AI model, connect your own server endpoint in Settings.

Where are my creations stored?

In your browser, using IndexedDB, up to 100 items. It isn't cloud storage, so clearing site data removes them. Use Backup library in Settings to keep a copy.

Can I make video?

Only with a connected backend that returns a finished video URL. The built-in renderer makes images.

What does it cost?

NOIR is a front-end project you run yourself, so it's free. Any cost comes from a generation service you choose to connect.

Does it work on a phone?

Yes. The layout adapts down to small screens, with a slide-out menu and touch-friendly controls.

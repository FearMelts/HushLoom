# Analysis material

Working material from the build sessions, kept in the repo so any later session can resume from it.

- `spec.md`: Jayvo's product specification (2026-10-12), condensed, with the name and look overrides.
- `addendum.md`: the four launch-readiness additions Jayvo approved on 2026-10-12, with their sources.
- `maps/`: nine read-only maps of the code at commit 9acac2e, each with file:line evidence. Line numbers
  drift as the code changes; re-check before relying on one.
- `audits/`: four audits of the code against the spec. Fix tracks A and B are built from their defect lists.
- `track-reports/`: the age-verification track's final report and the payments track's commit notes.

`notes/workflow/` holds the briefs every build track runs from and a script that restarts Postgres and Redis.

AI Generation Backend

Connect a server-side generation API. Leave this field empty to use the built-in procedural image preview. Video rendering requires a connected backend.

Use your own HTTPS endpoint or a same-origin route. Keep provider API keys on your server, not in this page. Variations are only available in the built-in demo renderer.

API Request Contract

Your endpoint receives a JSON request similar to:

POST /api/generate
Content-Type: application/json

{
  "type": "image",
  "prompt": "A cinematic midnight scene",
  "negative_prompt": "",
  "style": "cinematic",
  "aspect_ratio": "16:9",
  "quality": "high",
  "width": 960,
  "height": 540,
  "seed": 482913775
}

Return a completed image or video URL accessible to the browser:

{
  "image_url": "https://your-server.example/output.png"
}

OR

{
  "video_url": "https://your-server.example/output.mp4"
}

This client expects a completed media result. Async providers require a backend that resolves the job before responding. Cross-origin endpoints must allow your website's origin through CORS. Requests time out after 120 seconds and can be cancelled while running.

Local Storage

Creations and generation metadata are saved in this browser (IndexedDB), up to 100 items. This is not cloud storage or account synchronization. Back up regularly if you rely on your library.
